# 隐私与数据流

源码和应用运行数据分开管理。此公开仓库不包含原部署的配置、提交历史、设备档案、账号、日志、健康记录或签名密钥。

| 数据 | 保存/传输位置 |
|---|---|
| 管理员密码 | 只在初始化/登录时输入；服务器保存随机盐和 PBKDF2-SHA256 摘要 |
| 面板会话 | HttpOnly / SameSite Cookie；服务器保存可撤销会话，最长 7 天 |
| 模型 Key | 本地私有配置或中枢数据目录；模型请求发送给你选择的上游 |
| 小米凭据 | 中枢、健康服务各自的私有票据文件；用于连接小米云 |
| 设备状态和任务 | `data/bridge`；授权 AI 查询或操作时必要结果进入模型上下文 |
| 健康原始记录 | `data/health`，由独立服务管理 |
| 健康 AI 摘要 | 工具默认关闭；启用后仅在相关请求中传给所选模型 |
| 天气与搜索查询 | 对应公开天气服务或你配置的 SearXNG |
| Android 配置 | 用户输入服务器地址；密码使用本机 Android Keystore 加密 |

自托管不表示完全离线：小米登录/同步会访问小米云，外部模型、天气或搜索功能会访问相应上游。不要在 Issue、PR、截图或审计报告中上传私有配置、Cookie、真实对话和健康信息。

公开版安全默认值：只绑定回环地址、管理员登录开启、网关 Key 校验开启、健康 API 使用独立随机 Key、健康 AI 和额外外联工具关闭。用户可按自己的访问需求显式修改。

数据删除与备份由部署者控制。清空聊天不会删除健康库，卸载 Android 不会删除服务器数据，Git 忽略规则也不能代替加密备份。分享问题时请用模拟响应复现。
