# 首次公开检查 · v0.1.0

检查日期：2026-10-26。发布内容为独立的通用源码快照，原私有仓库和部署历史不随之公开。

## 数据与权限

- 从明确的源码与模拟测试清单导出；不复制运行目录、数据库、凭据、健康记录、设备清单、访问日志、备份、旧截图或 APK 签名密钥。
- 私有地址、域名、本机路径和个人测试标识替换为示例；运动格式测试使用虚构记录。文档截图来自完全模拟的离线浏览器。
- 公开目录使用 Gitleaks 8.30.1 检查，并单独运行 `python3 ops/audit_public.py`；最终公开提交历史也需通过 Gitleaks。四处明确的测试凭据只按行标注为合成脱敏样例，没有全文件或全规则豁免。
- 本机额外对照运行环境中的凭据值检查源码；未发现匹配，也未输出或上传这些值。
- 没有默认管理员，创建密码至少 12 位且输入两次；登录、会话、CSRF 和网关令牌默认开启。配置文件为 0600，端口默认只绑定回环地址。
- 可选健康服务使用独立随机密钥和独立数据目录，健康 AI 读取权限默认关闭。网页访问密钥仅存于标签页 sessionStorage，经请求头发送，可主动清除。
- Android 禁用应用备份，不分发原部署者的签名密钥或 APK。

## 验证范围

所有设备、模型和健康请求使用模拟数据；未调用真实设备、付费模型或同步真实健康记录。首次发布没有构建或发布 Android APK：本次环境没有 Android SDK/JDK，只检查了通用构建脚本的语法和配置。可选官方模型 SDK 用例未安装依赖，已明确跳过。

当前音箱支持中国区，健康统计使用北京时间。公网健康服务需要单独配置身份访问控制，面板登录不能替代其权限。具体部署和数据流见 [DEPLOYMENT](DEPLOYMENT.md) 与 [PRIVACY](PRIVACY.md)。
