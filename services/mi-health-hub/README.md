# 独立健康空间

将自己的小米手表云数据同步到本地 SQLite，展示活动、睡眠、心率、运动记录及每日/每周/每月趋势。此服务与中枢的数据目录、凭据与 API 权限分离。

从仓库根使用 `python3 ops/setup.py init --with-health`。没有内置健康记录或个人参数；先登录自己的小米健康账号，且手机端已上传手表数据后，云同步才可能读到记录。默认使用独立随机 API Key，外部 AI 和定时哨兵需按自己的需求开启。

中枢仅通过只读 API 联接健康空间，不能直接打开健康数据库。健康页面的 API Key 不等于中枢管理员登录；公网访问必须额外部署访问控制。

打开健康页面后，受保护的接口会提示输入健康 API Key。管理员从本地 `config/health-api-key` 获取，勿发送到 Issue 或聊天记录。网页只在当前标签页的 sessionStorage 中保存密钥，通过请求头发送；可在页面清除，不写入 URL 或 localStorage。

Python 3.11+；本地开发使用 `pip install -e '.[dev]'`，运行 `python -m pytest -q`。测试使用临时数据库和模拟云接口，不连接真实小米、模型或健康服务。完整命令见根目录[开发说明](../../docs/DEVELOPMENT.md)。
